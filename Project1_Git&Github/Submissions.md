## Status Guide

- ⏳ **Pending** — The team has not submitted, or its submission has not yet been reviewed.
- 📨 **Submitted** — A Pull Request has been opened and is awaiting review.
- 🔄 **Changes Requested** — The team needs to make requested corrections.
- ✅ **Approved / Merged** — The submission has been reviewed and merged.

## Submission Rules

1. Replace `—` with the working Live Project URL and Source Code repository URL when ready.
2. Update the status only as appropriate for the team's submission stage.
3. Each team must edit **only its own row**.
4. Do not delete, rename, or modify another team's row.
5. Do not merge your own Pull Request; wait for the instructor/reviewer.
6. The Tech Lead listed above is the first member in the supplied team allocation. If the team lead assignment changes, update the relevant row with the team's confirmed lead.
